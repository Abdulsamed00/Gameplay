# Gameplay

Unity 6 (6000.3 LTS) / URP gameplay vertical slice: third-person character controller, melee combat with game feel, and enemy AI.

## Structure
- `Assets/_Project/Scripts` – Core, Player, Combat, Enemies, UI, Systems
- `Assets/_Project/ScriptableObjects` – data-driven definitions (enemies, weapons)
- `Assets/_Project/Prefabs`, `Scenes`, `Art`, `Audio`, `Input`

## Packages
Input System, Cinemachine, AI Navigation, URP.
